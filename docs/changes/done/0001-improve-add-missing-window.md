# 0001 — Improve "Add missing" layout

> Status: **open** · Type: **feature** · Created: 2026-06-24

## Goal
Add missing food item window needs to be more intuitive.

## Context
The text fields order is not what user expects. 
Change layout to:
Calories - Protein
Carbs - Sugar
Fat - Saturated fat
Fiber - Salt

Besides layout text fields need to show labels even when value is in them. Ideally do a classic animation(I think its native in Android) where placeholder (eg Protein(g)) moves to top-left corner textfield and sits on its outline and its font gets smaller.

## Acceptance criteria
- [x] Layout changed
- [x] Text field names are readable when they have values in them
